단축키

V 클릭·이동 / B 펜 / T 텍스트 / E 지우개

T 후 보드 클릭 → 텍스트 입력 / Esc 또는 바깥 클릭으로 확정

휠 패닝 / Shift + 휠 가로 패닝

Ctrl(Cmd) + 휠 커서 기준 줌

Space + 드래그 / 휠클릭 드래그 핸드 이동

Ctrl(Cmd) + + / - / 0 줌 제어

Ctrl(Cmd) + Z / Shift + Z 실행취소/다시실행

Ctrl(Cmd) + C / V 선택 이미지 복사/붙여넣기

Ctrl(Cmd) + [ / ] 뒤로/앞으로 한 칸 이동

Ctrl(Cmd) + Shift + [ / ] 맨뒤/맨앞 보내기
