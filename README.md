# Live Board MVP

피그마 느낌의 **웹 기반 실시간 협업 보드**입니다. 같은 주소에 접속한 모든 사람이 하나의 보드를 함께 보고 편집합니다.

## 포함 기능

- 실시간 스케치(펜) — 부드러운 곡선 렌더링
- 텍스트 — T 누르고 보드 클릭 → 입력, 드래그 이동
- 지우개 — 선을 실제로 잘라내는 방식(벡터 클리핑)
- 이미지 업로드·드래그 이동·네 모서리 리사이즈·레이어 순서 조정
- 무한 캔버스 + 줌/패닝
- 실행취소/다시실행, 복사/붙여넣기, 단축키
- **다중 접속 실시간 동기화** — 늦게 접속한 사람도 현재 보드 상태를 그대로 받습니다.
- 참여자(presence) 표시

## 동작 방식 (기술 요약)

- 동기화는 **SSE(`/events`) + HTTP POST(`/sync`)** 로 동작합니다. (WebSocket 아님)
- `server.js`가 클라이언트들이 보낸 메시지를 중계하고, **최신 보드 스냅샷을 보관**합니다.
- 새 클라이언트가 접속하면 서버가 보관 중인 스냅샷을 그 클라이언트에게만 한 번 내려줘서, 늦게 들어와도 동일한 화면을 봅니다.
- 같은 브라우저의 여러 탭 간에는 `BroadcastChannel`로도 동기화됩니다.

## 로컬 실행

```bash
npm install
npm start
```

브라우저에서 `http://localhost:4173` 접속. 같은 주소를 다른 PC·브라우저에서 열면 실시간으로 같은 보드를 공유합니다.

## 인터넷에 공개해 다른 사람과 함께 쓰기

> **중요:** GitHub Pages(`*.github.io`)에서는 다중 접속 공유가 **안 됩니다.** Pages는 정적 파일만 호스팅하고 `server.js`(Node 서버)를 실행하지 못하기 때문에, 거기서는 같은 브라우저 탭끼리만 동기화됩니다. 진짜 다중 접속을 하려면 Node 서버를 실행할 수 있는 호스트가 필요합니다.

비개발자용 단계별 배포 방법은 [`DEPLOY.md`](DEPLOY.md)를 참고하세요.

## 한계 (현재 MVP 기준)

- 동시에 같은 객체를 편집하면 "마지막 동작이 반영"됩니다. (피그마급 정교한 충돌 해결 미구현)
- 보드 상태는 서버 메모리에만 보관되므로 서버가 재시작되면 초기화됩니다.
- 이미지는 base64로 저장·전송되어 대용량 이미지가 많으면 무거워질 수 있습니다.
